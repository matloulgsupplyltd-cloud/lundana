LULOMINE - static website (plain HTML)

Open index.html in a browser, or upload the whole folder to any web host.

PHOTOGRAPHS: the six supplied photographs are in the "media" folder and used across the pages.
They are labelled "Illustrative photograph" on the site because they do not show Lulomine's own
sites. If any are Lulomine's own, search the HTML files for "Illustrative photograph" and delete that caption line.

CONTACT FORM: a static site cannot receive form submissions by itself. Create a form endpoint
(e.g. Formspree) and replace FORM_ENDPOINT_NOT_SET in index.html, contact.html and procurement.html
with its URL. Until then the form shows an error and sends nothing.

Company email/phone/address are not filled in; search for "Direct contact details will be published here".
Certificates and tenders are not shown until you add real ones.
Not included in the static version: the admin panel, uploads, saved enquiries.
